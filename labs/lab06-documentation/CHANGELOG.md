# Changelog

Les changements notables du module Python `geo` sont consignés ici.

## [1.0.0] - 2026-10-29

### Ajouté

- Première version du module `geo.py`, avec le type `Point` et les fonctions de
  distance, de recherche dans un rayon, de recherche du point le plus proche et
  de formatage des coordonnées.
- Tests de comportement du module.
